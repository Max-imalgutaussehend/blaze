# Blaze

Extremely fast Rust tooling: one toolchain, parallel by default, content-hash caches.
Docs and benchmarks: https://max-imalgutaussehend.github.io/blaze/

| Tool | Role | Compared with |
|---|---|---|
| <img src="brand/ember.svg" width="18"> `ember` | linter (token-level, 6 rules) | clippy |
| <img src="brand/forge.svg" width="18"> `forge` | formatter (comment-preserving, verified) | rustfmt |
| <img src="brand/spark.svg" width="18"> `spark` | test runner (process per test, optional result cache) | cargo-nextest |
| <img src="brand/ward.svg" width="18"> `ward` | dependency policy (licenses, bans, duplicates, sources) | cargo-deny |
| `blaze` | umbrella; unknown subcommands go to cargo | cargo |

```sh
curl -LsSf https://github.com/Max-imalgutaussehend/blaze/releases/latest/download/install.sh | sh
blaze check
```

## Measured results
See the [benchmarks page](https://max-imalgutaussehend.github.io/blaze/benchmarks/). Reproduce with
`cargo build --release && python3 bench/run.py <corpus> <crate>`. Headline caveats:
ember is far smaller than clippy, forge's style is not rustfmt's, and cache-based speedups
describe repeat runs.

## Website & playground
`site/` is a Vite + React + Tailwind app (charts: [bklit ui](https://bklit.com); design tokens after the Raycast style from Refero). The playground runs the real ember and forge compiled to WebAssembly (`crates/blaze-wasm`). Build: `site/scripts/build-wasm.sh && cd site && npm ci && npm run build`.

Logos are generated by `brand/make_logos.py`: a Rust-style cog ring with rivets and a tool glyph in the hub.
