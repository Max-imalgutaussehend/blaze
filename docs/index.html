Blaze

One fast binary for linting, formatting, testing and dependency checks in Rust.

cargo build --release
blaze fmt --check && blaze lint && blaze test && blaze deny

Commands

BlazeReplacesState
lintclippy6 syntactic rules
fmtrustfmtskips files with comments
testnextestprocess per test, parallel
denycargo-denyno advisory DB yet
otherscargoforwarded

Benchmark

2000 comment-free files: rustfmt --check 39.6 s vs blaze fmt --check 1.1 s. Not like-for-like: Blaze uses prettyplease's style, and rustfmt also follows mod children.

Limitations

Early alpha. No comment-preserving formatting, no type-aware lints, no RustSec advisories, no resolver of its own.
